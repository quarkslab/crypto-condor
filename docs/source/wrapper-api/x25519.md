# X25519 Python wrapper

```{currentmodule} crypto_condor.primitives.x25519
```

## Key exchange

### Naming convention

The key exchange function must be named:

```
CC_x25519_exchange
```

### Protocol

```{eval-rst}
.. autoprotocol:: Exchange
    :noindex:
```

## Key pair generation

### Naming convention

The key pair generation function must be named:

```
CC_x25519_keygen[_nbytes]
```

Where:

* ``nbytes`` is an optional parameter, indicating how many bytes to generate
  with the keygen function. By default, the test generates 10 000 000 bytes. The
  minimum is 100 000 bytes.

### Protocol

```{eval-rst}
.. autoprotocol:: Keygen
    :noindex:
```
