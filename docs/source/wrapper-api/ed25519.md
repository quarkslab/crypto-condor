# Ed25519 Python wrapper

```{currentmodule} crypto_condor.primitives.ed25519
```

## Signing

### Naming convention

The signing function must be named:

```
CC_ed25519_sign
```

### Protocol

```{eval-rst}
.. autoprotocol:: Sign
    :noindex:
```

## Verifying

### Naming convention

The verifying function must be named:

```
CC_ed25519_verify
```

### Protocol

```{eval-rst}
.. autoprotocol:: Verify
    :noindex:
```

## Key generation

### Naming convention

The key pair generation function must be named:

```
CC_ed25519_keygen[_nbytes]
```

Where:

* ``nbytes`` is an optional parameter, indicating how many bytes to generate
  with the keygen function. By default, the test generates 10 000 000 bytes. The
  minimum is 100 000 bytes.

### Protocol

```{eval-rst}
.. autoprotocol:: Keygen
    :noindex:
```
